The domain blocks the whole site and all its subdomains (e.g. facebook.com)
With all child pages blocks that section and everything under it (e.g. reddit.com/r/gaming/*)
Exact page blocks that single page only (e.g. x.com/explore)
The domain allows the whole site and its subdomains (e.g. x.com)

Note: Allowing a specific section or single page restricts that site to only those allowed paths; the rest of the site is automatically blocked.

Synchronization Architecture

BlockX maintains unified configuration across profiles and devices using two independent layers.

Active Default

Account Sync

Shares settings across every profile signed into this Google account on any device. Fully automatic with zero setup required.

Local Machine

Settings File

Enforces unified settings for every profile on this computer regardless of Google account. Requires the local helper daemon.

Native Helper Daemon

A lightweight companion script (native/blockx_host.py) that allows the browser to read and write the local configuration file.

Run the installer once per machine in your terminal. Python 3 is required (standard on macOS/Linux; on Windows, check "Add Python to PATH").

cd <the BlockX folder>/native
python3 install.py
Restart the browser completely after running. Check Settings → Shared Settings to verify the active file status.

Configuration Storage & Integrity

Locations of the shared configuration file and tamper-protection behavior.

Linux ~/.config/blockx/settings.json
macOS ~/Library/Application Support/BlockX/settings.json
Windows %APPDATA%\BlockX\settings.json
Tamper Protection

Every write includes a cryptographic checksum. Hand-edits that tighten protection are accepted immediately, while edits that loosen protection are rejected and rewritten to prevent bypassing the deletion delay.

Troubleshooting & Diagnostics

Common solutions for file detection and communication issues.

Settings file status stays orange

Quit the browser completely and restart it (browser startup is when native registrations are loaded). On Linux, ensure the installer found your browser binary.

"Specified native messaging host not found"

The current browser was not registered during install. Re-run python3 install.py and verify that your browser is listed.

Settings file does not exist yet

The file is written automatically upon the first settings change. Toggle any rule in the dashboard to trigger initial file creation.

Uninstalling the helper

Execute python3 install.py --uninstall from the native/ directory. Your saved settings file is safely retained.
